# 星遇后台 · 本机联动 Mock 副本

此目录基于正式后台 v1.0.2.0 的页面与样式，提供合成数据和本机 Mock。它与桌面同级的 `小程序` 副本可以共享演示订单，不连接正式 API、数据库、微信支付、短信、柜机或其他真实业务服务。

## 启动与体验

1. 保持 `/Users/tantan/Desktop/WEB` 和 `/Users/tantan/Desktop/小程序` 两个目录并列。
2. 在本目录运行 `npm run dev`，打开 http://127.0.0.1:5190/。这个服务同时提供 WEB 页面和本机共享 Mock，仅监听 127.0.0.1。关闭服务后，小程序联动请求会失败，请重新启动。
3. 在微信开发者工具导入 `/Users/tantan/Desktop/小程序`，点击「编译」。本机开发配置关闭了该副本的合法域名校验，以允许开发者工具访问本机 HTTP 服务；这不适用于发布或真实联调。
4. 在小程序创建或推进订单，WEB「订单管理 → 租赁订单」会自动刷新，显示相同订单号、金额和状态；在 WEB 完成支持的模拟收回或超期费用最终审核后，小程序重新读取会看到状态变化。模拟支付、归还和退款均不会发生真实扣款或开柜。
5. 在小程序签到后，在 WEB「用户与会员」找到「林沐 · 演示账号」并打开用户档案；签到记录、粉钻余额和星光会从同一份共享数据自动刷新。旧后台样例会员仍保留。

## 数据与范围

小程序共享数据保存在 `WEB/.linked-mock/state.json`；首次连接且共享文件尚不存在时，复制当前小程序独立演示数据作为初始值，不删除旧数据。若共享文件已经存在，以现有共享文件为准；旧小程序数据仍保留在原本地存储命名空间。不要手动覆盖或删除共享数据文件，需先备份。小程序演示中心的重置会重置两端共享演示数据，不删除旧的独立数据。

WEB 原有演示样例继续存放在本机浏览器，包含商家、柜机、商品、资产、36 笔后台样例订单及其他页面数据；小程序共享订单与后台样例订单同时显示。订单、支付及退款记录有共享投影；会员列表额外展示一个共享演示账号，其档案的签到记录、星光和粉钻余额来自小程序共享状态，优惠券列表也显示该账号实际持有的共享券。共享订单支持待核实、补材料、损失凭证和最终审核，最终费用按押金差额生成退押或补缴。后台审核上传的 PNG、JPEG、WebP 仅保存在本机，每张不超过 5 MB。新演示订单冻结租赁单价；早期样例未存计费快照，超期预览使用对应演示设备的当前单价。

小程序演示补充页的商城兑换、服务购买、模拟提现和异议记录写入同一份共享状态；商城扣减后的粉钻余额可在后台共享账号档案查看。商城及异议仍为演示补充。

商品表单支持创建新品牌及分类；未修改过的旧样例会按其原始身份修正品牌/分类，用户编辑过的记录保留。后台此后明确保存或变更状态的标准商品会同步到小程序发布目录，只有启用商品可选；已有后台商品须先保存或变更状态，不自动覆盖历史数据。后台商品图片、视频、商家/门店及资产还没有完整联动。小程序归还时可使用演示图片或本机相册 PNG、JPEG、WebP 图片（单张不超过 5 MB），这些图片仅存本机并可在后台查看。关联资产数量按当前后台资产记录计算。柜机二维码为本地示意图。

按 `Alt + Shift + P` 可打开后台预览辅助工具。后台辅助工具的重置只影响后台浏览器样例；本地选择的 Blob 素材刷新后需重新选择。

## 验证与改造

- 页面与样式：`src/features/`、`src/styles/`；后台 Mock：`src/preview/`；本机联动服务：`local-mock/`。
- 可运行 `npm run verify` 和 `npm run check:api`。测试和限制见 [VERIFICATION.md](./VERIFICATION.md)。
- 这仍是演示替身。没有完成所有 API 分支、真机或全部页面的逐像素验收；正式源码、真实支付、签约、身份认证、物流及硬件均未联调。
