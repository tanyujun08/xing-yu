# 星遇小程序 · 本机联动 Mock 副本

此目录基于正式小程序 v1.0.2.0 的 54 个原生页面及组件，使用本机合成数据。它可以与桌面同级 `WEB` 副本共享订单，无需连接真实 API。

## 打开方式

1. 先启动 `/Users/tantan/Desktop/WEB` 中的本机服务：运行 `npm run dev`，并保持该终端运行。WEB 预览地址是 http://127.0.0.1:5190/。
2. 在微信开发者工具导入 `/Users/tantan/Desktop/小程序`，保留已配置的 AppID、TypeScript 插件与 npm 组件，点击「编译」。本副本的开发者工具私有配置关闭了合法域名校验，专供访问本机 HTTP Mock；不要将此设置作为真机、合法域名或发布验收依据。
3. 默认进入原生首页。小程序下单、签约、模拟支付、归还和退款状态会由本机共享服务处理；WEB 订单列表可显示同一笔订单。若提示本机服务不可用，先检查第 1 步。
4. 顶部编译模式可选择「离线演示中心」，体验角色、跨日签到、模拟交付与退款结果。演示中心的重置会影响两端共享演示数据，并明确要求确认。

## 数据和限制

首次连接时，如果 `WEB/.linked-mock/state.json` 尚不存在，会复制此副本现有的小程序演示数据作为共享初始值；原独立命名空间不删除。共享文件已存在时以共享文件为准，旧独立数据仍保留。请勿手动覆盖或删除该文件；需要备份时复制整个 `.linked-mock` 目录。

订单及其支付、退款投影可在两端查看；WEB 支持模拟收回、待核实、要求补材料，以及包含超期和损失费用的最终审核，小程序重新读取后显示同一状态。小程序签到后，WEB「用户与会员」的共享演示账号档案可查看同一签到记录、粉钻余额和星光；后台优惠券列表同时展示该账号实际持有的共享券和原有后台样例。真实支付、签约、身份认证、物流、客服、柜机和短信均为本地替身。

商城兑换、服务购买、模拟提现和异议页面是演示补充：操作成功后写入共享状态，粉钻余额与小程序优惠券等页面可回读；服务不可用时不会提示成功。后台此后新建或修改的标准商品会进入共享目录，只有启用的商品在小程序发布选择中显示；已有后台商品需要实际保存或变更状态后才同步，不自动覆盖历史数据。后台商品图片和商家/门店尚未完整联动。归还时可选择演示图片或本机相册的 PNG、JPEG、WebP 图片，单张不超过 5 MB；图片仅存本机，可在后台查看。视频及其他类型素材尚未完整联动。

预置 24 台设备、20 笔多状态订单、3 个地址、12 张优惠券、积分流水和发布草稿。原页面结构和样式继续用于视觉改造。详细规则见 [RULES.md](./RULES.md)，实际验证范围见 [VERIFICATION.md](./VERIFICATION.md)。

本次本地规则与网络替身测试通过，但没有完成原生模拟器的双端全流程、真机或全部 API 分支/逐像素视觉验收。只回用视觉修改到正式产品，不要把 Mock、本地自动登录或状态机复制到正式产品。
