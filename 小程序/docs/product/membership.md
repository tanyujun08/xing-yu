# 会员、粉钻、星光与活动

本页同时记录已接 API 的签到、权益投影与仍使用本地展示数据的活动。奖励以服务端回执和本人权益读取为准，不从页面文案推导真实发券或第三方权益交付。

<a id="mp-check-in"></a>

## MP-CHECK-IN 每日签到

路由：`pages/check-in/index`。源码：[check-in](../../miniprogram/pages/check-in/index.ts)。登录后读取 `GET /v1/me/check-ins?month=YYYY-MM`、`GET /v1/me/check-in-rule` 和本人权益摘要。服务端北京时间决定今日；月历与历史来自本人签到事实和原奖励快照，当前规则来自已发布 v2 配置。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| `checkIn` | 本人已登录、今日未签且有可用已发布规则；原意图键防重复 | 服务端回执显示本次奖励，再重读月份事实、规则与权益；未知结果保留原意图重试 |
| 月历与历史 | 本人月份查询 | 按服务端签到日期和原奖励快照展示；无发奖记录仍计为已签；跨月日期不误标未签 |
| 当前规则 | 有已发布 v2 版本 | 显示每日、首次与里程碑；无规则时按钮不可用，不展示猜测数值 |

签到页不提供补签、任务、抽奖、商城或提醒的假动作；这些能力如在其他页面存在，仍按各自接口和配置独立验收。切换账户或隐藏页面时清除本人投影，跨北京时间零点重新向服务端读取。

<a id="mp-membership"></a>

## MP-MEMBERSHIP 会员中心

路由：`pages/membership/index`。源码：[membership](../../miniprogram/pages/membership/index.ts)。登录后展示星光、粉钻、今日成长与等级进度；阈值 0/500/2000/6000/15000/30000/60000 对应普通到金钻。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| 星光/粉钻明细、商城、签到、权益 | 固定入口 | 去对应详情，不增减余额 |
| `openTask` | section+index 必须命中现有行 | 升级/每日任务→成长任务；信用免押→规则页；发布额度→额度页 |
| `copyInvite` | 点击邀请 | Toast“邀请权益暂未开放”；没有复制邀请码或邀请奖励 |
| 返回 | 普通返回 | onShow 重取账户数据 |

商城数量 `shopCount=12` 为固定展示；不当作实时可兑数量。

**展示与入口：**等级卡显示等级名、星光、下一等级与还差分数；进度按当前等级和下一等级阈值之间的比例取整并限制0–100%，最高等级显示100%和“已达最高等级”。粉钻是独立余额。今日成长当前按成功权益记录的UTC日期前缀汇总starPoints，与签到/抽奖的本地日键分别计算。

| 功能 | 入口与触发 | 交互逻辑 | 必要校验 | 结果与例外 |
| --- | --- | --- | --- | --- |
| 查看星光/粉钻 | 点对应资产入口 | 分别到star-ledger/powder-ledger | 页面先处理登录，目标页读取本人记录 | 查看不领取奖励、不兑换现金 |
| 查看等级权益 | 点等级详情 | 去level-rights，展示当前和下一档 | 按当前星光计算档位 | 当前非黄金/白金部分权益数组为空，不能补写已开通能力 |
| 完成成长任务 | 点升级/每日任务行 | 去growth-tasks，再去资料、实名、签到或发布来源页 | 行索引有效；已完成任务只提示，不重复领取 | 奖励来自实际完成命令，浏览页面不会自动完成任务 |
| 查看免押/额度 | 点信用免押/出租发布额度 | 分别去说明/发布额度页 | 有效行；具体操作由目标页校验 | 查看说明不改变免押资格；购买额度才产生扣减 |
| 邀请 | 点邀请入口 | 显示暂未开放提示 | 无可执行邀请命令 | 不复制邀请码、不发奖励 |

<a id="mp-level-rights"></a>

## MP-LEVEL-RIGHTS 等级权益

路由：`pages/level-rights/index`。源码：[level-rights](../../miniprogram/pages/level-rights/index.ts)。登录后按当前星光算等级、下一档与剩余分数。

`openStarLedger/openGrowthTasks` 分别去明细/任务。当前权益数组主要针对黄金档及下一档白金，其他档权益数组为空；“每月免押次数/优先服务”等描述不等于命令已强制实现额度规则（GAP-09）。

<a id="mp-growth-tasks"></a>

## MP-GROWTH-TASKS 成长任务

路由：`pages/growth-tasks/index`。源码：[growth-tasks](../../miniprogram/pages/growth-tasks/index.ts)。登录后用成功 growth_task、身份认证、签到记录计算部分升级任务。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| `openTask` | index 有效；已完成只提示，未完成去来源页 | 资料/实名/首次签到/发布的实际奖励在各自完成命令触发，不在这里领取 |
| `openMission` | 有对应每日任务；先弹进度说明，确认去完成 | 浏览 5 台、10 点位、3 指南等进度当前为静态值，不会因跳转自动累计 |
| `toggleBrowse/openBrowseMission` | 展开细项；有效 index | 只展开或导航，无独立计时、阅读完成、奖励提交 |

当前“首次签到 +50 星光”说明与签到命令固定 +20 星光不能合并为已实现双奖励；指南任务部分路由无 id 会落 missing。详见 GAP-09。

任务进度与领取关系：资料、身份、发布奖励在相应成功命令中写权益记录，本页没有“领取奖励”命令；每日浏览任务的进度说明和去完成弹框只负责引导。展开浏览细项不会提交计数。再次进入页面重查已成功记录，静态浏览进度仍按当前展示配置。

<a id="mp-powder-ledger"></a>

## MP-POWDER-LEDGER 粉钻明细

路由：`pages/powder-ledger/index`。源码：[powder-ledger](../../miniprogram/pages/powder-ledger/index.ts)。账户余额、收入/支出及现金相关展示取当前账户视图。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| `setLedgerFilter` | all/income/expense；重复选择不重载 | 切换清空旧查询展示并首屏加载；游标分页 |
| 下拉/触底/首屏、刷新、更多重试 | 控制器区分状态和请求代次 | 增量失败保留已有记录；生命周期释放；不能把加载失败当 0 余额 |
| 签到/商城/抽奖/钱包/规则 | 普通导航或规则弹框 | 钱包是现金业务入口；粉钻不通过本页兑换现金 |

源码残留 toggleCustom/withdrawAll/submitCustom 等提现方法，当前 WXML 未绑定；不作为现有粉钻提现功能。

明细筛选按全部/收入/支出展示记录，方向、积分数、说明和时间来自流水。空结果属于当前筛选；首次读取失败显示重试，已有列表加载更多失败保留旧项。与星光明细分别对应粉钻和星光余额，不能把两种积分相加或复用现金提现规则。

<a id="mp-powder-mall"></a>

## MP-POWDER-MALL 粉钻商城

路由：`pages/powder-mall/index`。源码：[powder-mall](../../miniprogram/pages/powder-mall/index.ts)。登录后按账户、月份回填兑换次数和余额。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| `selectCategory` | 合法分类：热门推荐、租赁优惠、出租服务、快递 | 默认热门推荐；换商品列表，不扣粉钻 |
| `redeem` | group/item 有效；当前月次数小于上限，或正在恢复原意图；余额充足；同一意图 singleFlight | 当前 `spendDiamonds` 扣粉钻并记账、更新兑换次数；不证明用户券包已新增可用券（GAP-10） |
| 重复/异常后重进 | 账户+券+月份+次数绑定意图、费用与标题指纹；用流水对账 | 结果未知保留原意图，不生成新的重复扣减；多条待确认时先刷新记录 |
| 签到/明细/抽奖 | 固定入口 | 不进行兑换 |

当前配置：10/20 元租赁券 1000/2000 粉钻、服务20券 2000、售后守护券 200、快递10券 1000，通常月限 10；置顶券 1000、月限 2。以源码配置核对，勿复制为永久业务配置。置顶执行与完整券消费流程不能从商品卡片推导。

商品卡展示名称、面额/说明、所需粉钻和本月已兑/上限；面额“元”与支付成本“粉钻”分别显示。点兑换先定位group/item，命中当前商品后检查额度和余额，再扣粉钻、记录兑换次数并刷新。余额不足或月限已满不扣减；未知结果先用原意图对照流水。当前没有独立券包页面和完整发券消费链路，不能把兑换成功提示写成已有可用优惠券。

<a id="mp-lottery"></a>

## MP-LOTTERY 每日抽奖

路由：`pages/lottery/index`。源码：[lottery](../../miniprogram/pages/lottery/index.ts)。登录后按本地日期成功记录计算剩余次数。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| `draw` | 非 drawing、每日成功次数<2；命令再查次数与余额≥20 粉钻 | 每次扣20，前端随机 8/18/28 粉钻或10星光，记本地奖励与消耗流水；失败清 busy，不弹中奖结果 |
| 关闭结果/遮罩阻止冒泡 | `closeResult/noop` | 只控制弹层，不撤销已记奖励或消耗 |
| `showRules` | 规则弹框 | 当前日最多2次，结果以记录为准 |
| 签到/浏览/订单 | 固定导航 | signedToday 仅展示，引导不等于抽奖强制先签到 |

文案提及优惠券，但当前奖池只有粉钻/星光；随机奖项由页面传入 Mock，不能迁为真实抽奖结算信任边界（GAP-10）。

抽奖展示余额、今日剩余次数和历史奖励。点击时先显示“正在确认抽奖结果…”，成功才打开结果弹层并减少剩余次数、增加记录；失败解除drawing并显示原因。关闭中奖弹层只收起结果，消耗/奖励仍保留。例：起始100粉钻，消耗20且奖中18粉钻，成功后余额98；奖中10星光则粉钻80并另加10星光。签到状态只作引导，不是本页抽奖的强制前置。

<a id="mp-no-deposit"></a>

## MP-NO-DEPOSIT 押金与免押说明

路由：`pages/no-deposit/index`，参数 `rentalMode=hourly` 或 `deviceId` 决定小时租说明，`from=profile` 调整标题。源码：[no-deposit](../../miniprogram/pages/no-deposit/index.ts)。

展示粉钻部分免押、微信免押、全额日租、小时押金说明及余额；小时模式只展示对应规则。当前 WXML 没有绑定业务事件，不能在此开通免押或修改资格。实际方案需在确认订单页选择并由命令校验。

**关键核对场景（预期，未运行）：**同一账户同一天签到两次，只增加一次20粉钻/20星光；星光达到2000时展示黄金档；余额不足兑换成本或月限已用完时不增加扣减/兑换次数；抽奖当天两次成功后第三次被拒，20粉钻以下不能发起成功抽奖；看完任务或免押说明返回，不凭导航增加星光或免押资格。
