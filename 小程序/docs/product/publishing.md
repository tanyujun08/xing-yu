# 个人设备发布与管理

本模块为 C2C 发布者使用；账户同时可以承租和出租，不存在靠页面切换取得的固定“出租方身份”。以下带 `MP-*` 编号的 Mock 页面说明是早期交互存档，**不再作为 v1.0.1.4 发布链路的实现事实或验收依据**；其中“审核后设价”、固定价格范围、Mock 审核任务、9 图/权属证明必填、面交和本地列表等叙述均不可用于当前施工。当前合同以治理 Change `XY-20260925-2b6213aa48184374bcc0fbf803b5181b@1`、API OpenAPI 和实时源码为准。

## v1.0.1.4 当前发布链路（本地源码候选，尚非 dev S3 通过）

- `pages/publish` 使用本人 `save/update/get/submitOwnAssetDraft`。本人从 ACTIVE 标准商品中选择商品；资格及 `getOwnAssetPublicationContext` 提供当前规则版本与可空价格建议。设备名称、自由描述成色、唯一标识类型和值、日租金、押金、最低租期、参考价值、可租起止日均在提交前由本人填写并保存；金额元→分使用十进制字符串。可选说明不因留空阻止个人提交。
- 用户主动调用 `wx.chooseAddress`，经行政区划匹配后创建/回读本人地址，快递/跑腿（API 值 `EXPRESS`/`RUNNER`）每项明确双程费用承担者和 `source_address_id`；不伪造经纬度。设备实拍通过第一方材料上传，READY 后绑定素材 ID，至少一张封面；本页不开放面交或把权属证明混为公开实拍。
- 保存和提交均保留原幂等意图，成功需同一 `draft_id/version` 回读。提交产生待审核、下架的个人资产；Admin 只批准或驳回最新待审版本，不补价。`pages/listings` 走本人清单和本人详情，可看到驳回理由、最新/当前版本及服务端上架阻断；本人详情不跳公开供给 API。
- 公开列表/详情只展示服务端已批准且 ONLINE 的个人资产，个人供给详情不展示下单/报价 CTA。本人可见与公开可见是两条不同读取链路。本次施工终点是商品资料可见，不包含订单。
- 本地类型检查、架构门禁和宿主机测试不是隔离 MySQL、Docker 镜像、真实 OSS/微信地址、开发者工具或真机验收；未运行项不得宣称通过。

## MP-PUBLISH-ELIGIBILITY 发布条件

路由：`pages/publish-eligibility/index`，可带 `section=quota|service` 改变标题。源码：[publish-eligibility](../../miniprogram/pages/publish-eligibility/index.ts)。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| 进入/重新显示 | 登录；读取账户身份认证、发布额度、合同/人脸/风控服务余额 | 未登录弹框去登录或返回；回来重新计算 publishEnabled |
| `openCheck` 条件项 | 点击已有 route | 打开会员、认证、额度或服务页；打开页面不视为达标 |
| 购买发布/出租服务 | 登录 | 分别去 publish-quota、rental-service，不在本页扣款 |
| `publish` | 未实名转认证；额度必须 >0 | 去发布表单；最终 createListing 再校验实名和额度 |

“黄金会员/LV3+ 已达成”和服务项 `done=true` 当前是固定展示；publishEnabled 只按实名+发布额度。不能写成已经实现的等级和三项服务余额强校验（GAP-06）。

用户路径：从首页“发布”或我的“我要出租”进入→查看未满足项→完成实名或购买额度→返回后重新计算资格→进入表单。实名仅交证件时仍显示“待完成人脸认证”；额度为0时发布提示“发布额度不足”。`section=quota/service` 只改变本页标题，不自动完成购买或绕过资格检查。

| 面交分支 | 地点、时间必填 | 不能用一个总地址字段冒充所有交接信息 |
| `saveDraft`、onHide/onUnload 自动保存 | 登录、非 view、非提交/跳转；没有 draftId 且品牌/型号/两类图片都空时不保存 | 保存不强制满足发布条件、不扣额度；编辑中保存可能转换为 draft 模式，后续创建语义见 GAP-08 |

<a id="mp-listing-price"></a>

## MP-LISTING-PRICE 草稿设价并提交审核

路由：`pages/listing-price/index?draft_id=…`；兼容已接入发布页使用 `mode=draft&id=…`。源码：[listing-price](../../miniprogram/pages/listing-price/index.ts)。页面只读取当前登录账号的权威草稿；访客、缺少草稿 id、非法 id、无权或不存在均失败关闭且不回退 Mock。`mode=view` 只读，只有 `EDITING` 草稿可修改并提交。

| 交互与触发 | 条件与校验 | 结果与恢复 |
| --- | --- | --- |
| 输入租金/押金 | 原样显示服务端分值金额，允许 0～2 位小数并按字符串精确换算为分；不使用 JS 浮点换算 | 无效精度、格式或越界时不发写请求；价格范围与提交资格由服务端校验 |
| 起止日期 | 页面显示上海时区自然日且结束日包含在可租期内；结束不得早于开始 | 写入时转换为 UTC 起始边界和下一日排他结束边界，其他资产字段完整保留 |
| `confirm` | 非 submitting、本人 `EDITING` 草稿；先持久化 UPDATE 原请求，再带 `If-Match` 与 `Idempotency-Key` 保存 | UPDATE 回执校验后必须 GET 同一草稿并逐字段核对，才清除保存意图并进入提交 |
| 提交审核 | 保存闭环完成后持久化 SUBMIT 原请求，再带原版本和幂等键提交 | SUBMIT 回执校验后必须 GET 同一草稿，核对 `SUBMITTED`、版本、资产和修订标识后才提示成功并进入草稿只读页；不宣称审核通过或已上架 |
| 失败与恢复 | 409/412/422 等明确拒绝释放对应 PREPARED 意图并要求重读；超时、断网、5xx、无效回执或回读不一致保留原意图 | 重试复用完全相同的 body、版本和幂等键；已取得回执的位置意图只做权威 GET，不重复写入 |
| `edit/goBack` | 没有待核实意图时，编辑去 `publish?draft_id=…&mode=draft`；返回只导航 | 待核实期间禁止另开编辑页，防止覆盖原请求 |

设价页的名称、计费单位、租金、押金、可租期和交付方式均来自当前草稿 GET。页面不再读取本地 listing、指导价或旧 `setListingPrice` 命令，也不会把 API 失败解释为提交成功。当前“我的发布”仍为 Mock 列表且没有后端草稿清单 operation，故其待设价按钮只提示缺口；取得权威草稿 id 前不能进入本页。

**关键核对场景（预期，未运行）：**

- 只填品牌后保存草稿：允许保存且不扣额度；同样资料提交发布：显示缺项。
- 选快递资料完整后再勾选跑腿：补齐跑腿四项才允许提交；取消跑腿后不再要求这组字段。
- 日租输入199、800、801：分别超下限被拒、在当前范围、超上限被拒；还需满足其他必填条件。
- 权威草稿修改开始日期晚于旧结束：结束同步到新开始；结束改得更早：显示错误且不发写请求。
- UPDATE 或 SUBMIT 超时后再次点击：复用原 body、版本和幂等键；若回执已定位但页面离开，再进入只做 GET 核实。
- 有进行中订单时编辑/下架被拒，允许查看原资料；审核中记录不会因用户打开列表就成为可租商品。
