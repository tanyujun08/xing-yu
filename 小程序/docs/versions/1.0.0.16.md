## 本版本范围

- 保留当前原生微信小程序视觉改造：页头、页壳、无分割线 Tab、底部操作区、订单/归还/售后/沟通页面和会员相关页面。
- 补齐 Mock 主链路：C2C 下单、取件、归还、售后与纠纷、私聊、优惠券兑换与下单选券。
- 增加柜机专属优惠券规则：柜机小时租在归还验收后的最终租金结算抵扣，柜机日租在下单结算抵扣；通用租赁券与柜机券不交叉使用；优惠券只抵扣租金。
- 保持当前“只接 Mock、不接真实接口”的边界，不把支付、柜机、物流、OSS 或后台回调模拟结果写成线上能力。
